# 项目概览

**Moodial** — 开源、自部署优先的 AI 情绪日记应用

## 🎯 核心理念

**你的日记数据属于你。**

Moodial 相信数据隐私和用户控制的重要性。无论选择自部署还是官方托管，我们都确保：

- 你完全掌控自己的数据
- 清晰透明的数据处理流程
- 随时可以导出或删除数据
- 没有强制的数据收集或训练使用

## 📱 产品形态

### 自部署版本

在自己的 NAS、VPS、云主机或本地机器上部署 Moodial：

```bash
docker compose up -d
```

**优势**：
- 📍 数据完全在你的掌控范围
- 💰 一次性部署，无后续费用
- 🔐 最大隐私保护
- 👥 支持多用户和小团队

**场景**：个人用户、家庭、朋友小圈子、小团队

### 官方托管版本

注册官方账号，直接使用云端服务：

**优势**：
- ⚡ 开箱即用，无需部署
- 🤖 官方维护的 AI 模型服务
- 💳 灵活的计费方式（免费额度 + 按量/包月）

**场景**：不想自部署的用户、需要官方支持的用户

### 移动应用（规划中）

未来的移动应用可以：
- 📲 连接到官方账号
- 📲 连接到自部署实例
- 📲 支持离线录音和草稿

## ✨ 核心功能

### 四个情绪入口

**快乐** — 记录开心的事情  
**抱怨** — 发泄一下不满  
**难过** — 倾诉难受的感受  
**混乱** — 整理混乱的想法  

根据选择的情绪，AI 会使用不同的开场、追问和收束策略。

### AI 对话式记录

- 💬 自然聊天，不是填表格
- 🤖 AI 轻量追问，帮助你想清楚
- 🎯 自动收束，避免过度对话

### 自动化处理

- 📝 自动生成自然语言日记
- 🏷️ 提取结构化字段（事件、人物、地点等）
- 😊 识别和标记情绪标签
- 📊 支持后续分析和统计

### 日历回看

- 📅 日历视图查看历史日记
- 🔍 搜索和过滤
- 📈 情绪趋势可视化
- 📊 周/月报告（v0.2+）

### 多用户和数据隔离

- 👥 每个实例支持多个用户
- 🔒 用户之间日记完全隔离
- 🛡️ 基于角色的权限管理
- 🔑 支持邀请和自助注册

### 灵活的模型配置

- 🔌 支持 OpenAI、Ollama 等兼容接口
- 🎛️ 用户可自配置 API Key 和模型
- 🌐 支持国内大模型服务

## 📊 数据模型

核心实体：

- **UserAccount** — 用户账号和认证
- **DiaryEntry** — 日记记录（包含原始对话和生成的日记）
- **ChatSession** — 一次对话会话
- **ChatMessage** — 对话中的单条消息
- **AppSetting** — 应用配置（AI Key 等）
- **UsageRecord** — API 调用记录（计费用）
- **Subscription** — 订阅信息（官方托管）

详见[架构说明](architecture.md)。

## 🔐 隐私设计

### 自部署版本

✅ 数据完全在你的服务器上  
✅ 不依赖官方账号或服务  
✅ 支持本地 AI 模型（完全离线）  
⚠️  如果使用云端 AI API，对话会发送给模型服务商  

### 官方托管版本

✅ 提供清晰的隐私政策  
✅ 支持数据导出和删除  
✅ 日记不会用于模型训练（除非明确同意）  
✅ 使用加密存储和访问控制  

详见[隐私说明](privacy.md)。
