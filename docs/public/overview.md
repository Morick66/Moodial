# 项目概览

Moodial 是一个开源、自部署优先的 AI 情绪日记应用。

它通过自然聊天帮助用户整理当天发生的事、情绪、想法和感受，并生成可以回看的日记。项目同时支持官方托管服务，让不想自部署的用户也能直接注册使用。

## 产品形态

- 自部署：用户通过 Docker Compose 部署自己的实例，数据保存在自己的服务器、NAS 或云主机中。
- 官方托管：用户注册官方账号，使用官方服务器和官方模型能力。
- 移动端：后续移动端 App 可以登录官方账号，也可以连接用户自己的自部署服务。

## 核心能力

- 多用户账号系统；
- 用户之间日记数据隔离；
- 四个情绪入口；
- AI 聊天式记录；
- 自动生成日记；
- 结构化字段和标签；
- 日历回看；
- 数据导出；
- 官方模型订阅和用量统计。

## 技术栈

- Next.js App Router；
- React；
- TypeScript；
- Tailwind CSS；
- Prisma；
- PostgreSQL；
- Docker Compose；
- OpenAI-Compatible AI Adapter。
