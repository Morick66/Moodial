# 隐私说明

> 📋 **核心原则：你的日记数据属于你。**

日记是高度私密的个人数据。Moodial 的设计目标是让用户对自己的数据有完全的掌控和清晰的了解。

## 自部署版本的隐私

### ✅ 数据完全在你的掌控

- 日记完全保存在你的服务器、NAS 或云主机中
- 不依赖官方服务或账号系统
- 无需上传任何数据到官方服务器
- 支持离线部署（内网使用）

### ⚠️ AI 模型调用的考虑

如果配置了云端 AI API（如 OpenAI、Claude 等），对话内容会发送给相应的 AI 服务商：

```
你的输入 → 你的服务器 → AI 服务商 → 你的服务器 → 生成的日记
```

**隐私影响**：
- ⚠️ 对话内容会被 AI 服务商看到
- ⚠️ 可能被用于模型改进（取决于服务商政策）
- ✅ 但日记（最终结果）仍完全在你的服务器上

**最大隐私方案**：
使用自部署版本 + 本地 AI 模型（Ollama、LM Studio 等）

```
你的输入 → 你的服务器 → 本地模型 → 生成的日记
           （完全离线）
```

### 🔐 建议的最佳实践

对于极度敏感的内容：

1. **使用本地模型**
   - Ollama（推荐）
   - LM Studio
   - Llama.cpp

2. **在内网部署**
   - 不要暴露到公网
   - 使用防火墙保护

3. **定期备份**
   - 备份数据库和配置
   - 保存在安全位置

4. **启用 HTTPS**（如果需要远程访问）
   - 使用反向代理（Nginx/Caddy）
   - 获取 SSL 证书

## 官方托管版本的隐私

### 📋 数据存储

- 日记保存在官方服务器
- 采用数据库级别的加密
- 用户间数据完全隔离（SQL 层级）
- 定期备份以防数据丢失

### 👁️ 数据访问

- 只有你和授权的管理员可以访问
- AI 模型调用仅用于生成你的日记
- 日记不会被用于模型训练（除非你明确同意）
- 内部团队遵循最小权限原则

### 🔒 数据保护措施

- ✅ HTTPS/TLS 加密传输
- ✅ 数据库加密存储
- ✅ 定期安全审计
- ✅ 日志审计和监控
- ✅ 员工背景调查

### 📊 分析和统计

- 我们可能收集匿名化的使用统计
- 不包含日记内容或个人识别信息
- 用于改进产品和理解用户行为

**例**：
- ✅ 每月平均日记数量
- ✅ 最常用的情绪模式
- ✅ 最常使用的功能
- ❌ 具体的日记内容
- ❌ 个人身份信息

### 📤 数据导出

- 随时导出你的所有数据（JSON 格式）
- 导出包括日记、聊天记录、标签等
- 无需付费或提供理由

### 🗑️ 数据删除

- 随时删除单条日记
- 随时注销账号并删除所有数据
- 删除后 30 天内完全从备份中清除
- 无需付费

### 💳 计费和消费记录

- 保存你的计费历史和消费记录（法律要求）
- 计费数据与日记内容完全分离
- 你可以随时查看账单

## 数据安全

### 加密

| 层级 | 方法 |
|------|------|
| **传输** | TLS 1.3+ |
| **存储** | AES-256（加密字段） |
| **备份** | 加密备份 |

### 访问控制

- 基于 JWT 的认证
- 基于用户 ID 的数据隔离
- 管理员日志审计
- 异常检测告警

### 合规性

- 遵守数据保护法规（GDPR、CCPA 等）
- 定期安全审计
- 可追溯的审计日志

## 共享和协作

### 自部署版本

- 你控制谁能访问你的实例
- 可以创建多个用户账号
- 支持邀请链接
- 账号间数据隔离

### 官方托管版本

- 暂时不支持日记共享
- 未来版本可能支持：
  - 与特定用户共享日记
  - 只读访问权限
  - 评论和反馈

## 儿童隐私

- 官方托管版本会收集必要的年龄验证
- 不会向儿童展示不适当的内容

## 隐私政策变更

**自部署版本**：
- 由你完全掌控
- 无需遵守官方政策

**官方托管版本**：
- 重大变更会提前通知
- 你有权利拒绝新政策并导出/删除数据
- 每次变更后会标记版本号和生效日期

## 取消账号和数据删除

### 自部署版本

1. 导出你的数据（可选）
2. 停止 Docker 容器
3. 删除数据卷
4. 完成

### 官方托管版本

1. 登录账号
2. 进入设置 → 高级
3. 点击"删除账号"
4. 确认删除
5. 所有数据立即不可访问
6. 30 天内从备份清除
