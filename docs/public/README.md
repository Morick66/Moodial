## 📖 文档风格指南

Moodial 的文档遵循以下原则：

- 📍 **清晰准确** — 使用简洁的语言，避免歧义
- 🎯 **循序渐进** — 从基础到进阶，逐步深入
- 💡 **示例丰富** — 包含代码示例和操作步骤
- 🔗 **交叉链接** — 文档之间相互关联
- 🌍 **多语言** — 支持中英文（后续会添加更多）
