# 产品路线图

> 📈 **Moodial 的发展方向和计划**

本路线图展示了 Moodial 未来的功能规划。所有时间表都是估计，可能根据社区反馈和优先级进行调整。

## 当前版本：v0.1 MVP

**状态**：进行中  
**预计完成**：2026 年 Q3

### 核心功能

- ✅ Web 基础应用（Next.js + React）
- ✅ 多用户账号系统
- ✅ 自部署初始化流程
- ✅ 4 个情绪模式（开心、抱怨、难过、混乱）
- ✅ AI 聊天式记录
- ✅ 自动生成日记
- ✅ 结构化字段提取（事件、人物、地点等）
- ✅ 情绪标签识别
- ✅ 日历回看
- ✅ 日记删除和导出（JSON）
- ✅ Docker Compose 自部署
- ✅ PostgreSQL 数据库

### 验收标准

- [ ] 完整 Docker 部署验收通过
- [ ] 所有核心功能 E2E 测试通过
- [ ] 文档完整
- [ ] 开源发布

## v0.2：自部署体验增强

**预计**：2026 年 Q4  
**优先级**：高

### 部署和维护

- 📦 Docker Compose 完善（健康检查、自动重启等）
- 📚 详细部署文档
  - NAS 部署指南（群晖、威联通、Unraid）
  - VPS 部署指南
  - 云服务器部署（AWS、阿里云、腾讯云）
- 🔄 自动化备份和恢复
- 🧪 模型连接测试和诊断工具
- 🔔 系统监控告警

### 用户体验

- 📱 PWA 适配（可安装、离线支持）
- 📝 Markdown 导出
- 📊 周总结功能
- 🎨 深色模式
- 🌍 国际化（i18n）支持

### 技术改进

- ⚡ 性能优化（缓存、数据库索引）
- 🔒 安全加固
- 📈 监控和日志系统

## 社区贡献机制

我们欢迎社区参与！

### 贡献路径

1. 🐛 **Bug 报告** — 报告问题，帮助改进
2. ✨ **功能建议** — 分享想法，在 Discussions 中讨论

4. 📝 **文档改进** — 改进文档和教程

## 发布流程

- **主线分支**：`main` — 稳定版本
- **开发分支**：`develop` — 开发版本
- **特性分支**：`feature/*` — 功能开发
- **版本标签**：`v0.1.0` 等

### 发布周期

- **小版本** (v0.1.x)：月度 bug 修复和小功能
- **主版本** (v0.x)：季度功能发布
